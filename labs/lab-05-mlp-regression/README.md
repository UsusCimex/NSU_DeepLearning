# Лабораторная 5. Многослойный перцептрон для решения задачи регрессии

Синтетические выборки по функциям cos(2 pi x), 5x^3 + x^2 + 5, x sin(2 pi x)
на [0, 1] с нормальным шумом.

[Ноутбук](mlp_regression.ipynb) - собственная реализация обратного
распространения, 12 архитектур (один и два скрытых слоя, от одного до трёх узлов),
кросс-валидация, сравнение с полиномиальной регрессией. Замеры в `results.csv`.
