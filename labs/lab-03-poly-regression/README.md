# Лабораторная 3. Полиномиальная регрессия. Регуляризация. Кросс-валидация

Синтетические выборки по функциям cos x, 5x^3 + x^2 + 5, x sin x на [0, 2pi] с
равномерным и нормальным шумом.

[Ноутбук](poly_regression.ipynb) - решение нормальных уравнений вручную, степени
от 0 до 15, гребневая регуляризация, пятикратная кросс-валидация. Замеры в
`results.csv`.
