# Лабораторная 8. Автоэнкодеры

Датасет: MNIST, FashionMNIST для сравнения.

[Ноутбук](autoencoders.ipynb) - обычный автоэнкодер и вариационный, перебор
размерности латентного пространства, архитектуры кодировщика, коэффициента
обучения и числа эпох, шумоподавление для трёх видов шума, сравнение AE и VAE
по MSE и SSIM. Замеры в `results.csv`.
