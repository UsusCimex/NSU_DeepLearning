\zad{1} Доказать утверждение 1: $\xi \sim \mathrm{U}[0,1]$, $F$ -- функция
распределения $\Rightarrow$ $F^{-1}(\xi) \sim F$.

Обобщённая обратная: $F^{-1}(u) = \inf A_u$, $A_u = \{x \in \R : F(x) \ge u\}$.

\begin{lemma}
$F^{-1}(u) \le x \iff u \le F(x)$.
\end{lemma}
\begin{proof}
$(\Leftarrow)$ $u \le F(x) \Rightarrow x \in A_u \Rightarrow \inf A_u \le x$.

$(\Rightarrow)$ $A_u$ -- луч, так как $F$ не убывает. Его инфимум
$t = F^{-1}(u)$ лежит в $A_u$: $F(t) = \lim_{y \downarrow t} F(y) \ge u$
по непрерывности справа. Тогда $t \le x \Rightarrow F(x) \ge F(t) \ge u$.
\end{proof}

Пусть $\eta = F^{-1}(\xi)$. По лемме $\{\eta \le x\} = \{\xi \le F(x)\}$, значит
\[
  F_\eta(x) = \PP(\xi \le F(x)) = F(x), \qquad F(x) \in [0,1]. \qquad\blacksquare
\]
Использованы только неубывание и непрерывность справа, поэтому $F$ может быть
разрывной: способ работает и для дискретных распределений.

\prov $2\cdot10^6$ значений. $\mathrm{Exp}(1.7)$: $D = 0.00056$, $p = 0.56$.
Дискретное с $(0.5,\,0.2,\,0.3)$: макс. отклонение частот $0.0003$.

\zad{2} $\xi \sim \Normal(0,1)$, $\eta = \mu + \sigma\xi$, $\sigma > 0$.
\[
  F_\eta(x) = \PP\Bigl(\xi \le \tfrac{x-\mu}{\sigma}\Bigr)
            = \Phi\Bigl(\tfrac{x-\mu}{\sigma}\Bigr),
  \qquad
  \dens_\eta(x) = \tfrac{1}{\sigma}\varphi\Bigl(\tfrac{x-\mu}{\sigma}\Bigr)
  = \tfrac{1}{\sigma\sqrt{2\pi}}e^{-(x-\mu)^2/2\sigma^2},
\]
то есть $\eta \sim \Normal(\mu,\sigma^2)$. Параметры:
$\Exp\eta = \mu + \sigma\Exp\xi = \mu$, $\Var\eta = \sigma^2\Var\xi = \sigma^2$.
$\blacksquare$

При $\sigma < 0$ та же плотность с $\abs{\sigma}$, так как $\varphi$ чётна; при
$\sigma = 0$ плотности нет.

\prov $\mu = -3.5$, $\sigma = 2.25$, $2\cdot10^6$ значений: среднее $-3.4981$,
$\sigma_{\text{выб}} = 2.2518$; $D = 0.0029$, $p = 0.37$ по $10^5$ значениям;
$\max\abs{(\eta-\mu)/\sigma - \xi} = 4.4\cdot10^{-16}$.

\zad{4} $\xi = g(\zeta)$, $g$ монотонна и непрерывно дифференцируема. Замена
переменной:
\begin{equation}\label{eq:jac}
  \dens_\zeta(t) = \dens_\xi\bigl(g(t)\bigr)\abs{g'(t)}.
\end{equation}

\emph{Математическое ожидание.}
\[
  \Exp\xi = \int \dens_\xi(x)\,x\dd x = \int \dens_\zeta(t)\,g(t)\dd t
          = \Exp g(\zeta),
\]
то есть $\Exp\xi = \Exp\zeta \iff \Exp g(\zeta) = \Exp\zeta$, что для
произвольной $g$ неверно. По Йенсену $\Exp g(\zeta) \ge g(\Exp\zeta)$ для
выпуклой $g$, строго при строгой выпуклости; равенство для всех распределений
$\iff$ $g$ аффинна.

\emph{Мода.} Логарифмируя \eqref{eq:jac},
\[
  0 = \bigl(\ln \dens_\zeta\bigr)'(t_0)
    = \frac{\dens_\xi'\bigl(g(t_0)\bigr)}{\dens_\xi\bigl(g(t_0)\bigr)}\,g'(t_0)
      + \frac{g''(t_0)}{g'(t_0)} .
\]
Равенство $x_0 = g(t_0)$ требует $\dens_\xi'(x_0) = 0$, то есть $g''(t_0) = 0$.
Для нелинейной $g$ не выполняется.

\emph{Контрпример.} $\xi \sim \mathrm{Exp}(1)$, $g(t) = t^3$,
$\zeta = \xi^{1/3}$, $\dens_\zeta(t) = 3t^2e^{-t^3}$:
\[
  \Exp\xi = 1, \quad
  \Exp\zeta = \int_0^{\infty}\!\! 3t^3e^{-t^3}\dd t = \Gamma(\tfrac43) \approx 0.8930,
  \quad g(\Exp\zeta) \approx 0.7121;
\]
\[
  x_0 = 0, \quad
  \bigl(2\ln t - t^3\bigr)' = \tfrac2t - 3t^2 = 0
  \Rightarrow t_0 = (\tfrac23)^{1/3} \approx 0.8736,
  \quad g(t_0) = \tfrac23 \ne x_0 .
\]
Обе эквивариантности выполняются только для аффинной $g$.

\prov $2\cdot10^6$ реализаций: $\Exp\xi = 0.9985$, $\Exp\zeta = 0.8926$.

\zad{5} $\zeta = z(\xi)$.

\emph{Математическое ожидание не переносится.} $\xi \sim \mathrm{U}[0,1]$,
$z(x) = x^2$:
\[
  \Exp\zeta = \int_0^1 x^2\dd x = \tfrac13 \ne \tfrac14 = z(\Exp\xi).
\]
По Йенсену равенство для всех распределений $\iff$ $z$ аффинна.

\emph{Медиана переносится при монотонном $z$.} Пусть $z$ непрерывна и строго
возрастает, $m$ -- медиана $\xi$. Тогда $\{\xi \le m\} = \{z(\xi) \le z(m)\}$,
поэтому
\[
  \PP(\zeta \le z(m)) = \PP(\xi \le m) \ge \tfrac12,
  \qquad \PP(\zeta \ge z(m)) \ge \tfrac12,
\]
то есть $z(m)$ -- медиана $\zeta$; для убывающей $z$ то же с обращением
неравенств. Медиана определяется порядком, а $\Exp$ -- расстояниями между
значениями, которые нелинейное $z$ искажает.

\emph{Немонотонное $z$ медиану не переносит.} $z(x) = (x-\tfrac12)^2$:
\[
  \PP(\zeta \le m) = \PP\bigl(\abs{\xi - \tfrac12} \le \sqrt{m}\bigr) = 2\sqrt m
  = \tfrac12 \Rightarrow m = \tfrac1{16} \ne 0 = z(\tfrac12).
\]

\zad{6} Плотность многомерного нормального распределения
$\xi \sim \Normal(\mu,\Sigma)$:
\begin{equation}\label{eq:mvn}
  \dens(x) = \frac{1}{(2\pi)^{m/2}\det(\Sigma)^{1/2}}
  \exp\Bigl(-\tfrac12(x-\mu)^{\top}\Sigma^{-1}(x-\mu)\Bigr),
  \qquad \Sigma = (\sigma_{ij}), \quad
  \sigma_{ij} = \Exp\bigl((\xi_i-\mu_i)(\xi_j-\mu_j)\bigr).
\end{equation}
По заданию 7 независимость даёт $\sigma_{ij} = 0$ при $i \ne j$, значит
$\Sigma = \mathrm{diag}(\sigma_1^2,\dots,\sigma_m^2)$, $\sigma_i^2 > 0$. Тогда
\[
  \det\Sigma = \prod_{i=1}^{m}\sigma_i^2, \qquad
  \Sigma^{-1} = \mathrm{diag}(\sigma_i^{-2}), \qquad
  (x-\mu)^{\top}\Sigma^{-1}(x-\mu) = \sum_{i=1}^{m}\frac{(x_i-\mu_i)^2}{\sigma_i^2},
\]
и \eqref{eq:mvn} распадается:
\[
  \dens(x) = \frac{1}{(2\pi)^{m/2}\prod_i\sigma_i}
  \exp\Bigl(-\tfrac12\sum_{i=1}^{m}\tfrac{(x_i-\mu_i)^2}{\sigma_i^2}\Bigr)
  = \prod_{i=1}^{m}\frac{1}{\sigma_i\sqrt{2\pi}}
    e^{-(x_i-\mu_i)^2/2\sigma_i^2}. \qquad\blacksquare
\]
Обратное тоже верно, число параметров падает с $m + m(m+1)/2$ до $2m$.

\prov $m = 4$, $\mu = (1,-2,0.5,3)$, $\sigma = (1,2,0.5,1.5)$,
$x = (0.3,-1,0.9,2)$: плотность \eqref{eq:mvn} и произведение одномерных дают
$0.0067823$, разность нулевая в двойной точности.

\zad{7} Из независимости $\xi_i$, $\xi_j$ следует независимость
$\xi_i - \mu_i$, $\xi_j - \mu_j$, поэтому
\[
  \sigma_{ij} = \Exp\bigl((\xi_i-\mu_i)(\xi_j-\mu_j)\bigr)
              = \Exp(\xi_i-\mu_i)\,\Exp(\xi_j-\mu_j) = 0
\]
(нужны конечные вторые моменты). $\blacksquare$

Обратное неверно: $\xi \sim \mathrm{U}[-1,1]$, $\eta = \xi^2$ зависит от $\xi$,
но
\[
  \mathrm{cov}(\xi,\eta) = \Exp\xi^3 - \Exp\xi\,\Exp\xi^2
  = \int_{-1}^{1}\tfrac{x^3}{2}\dd x = 0
\]
по нечётности. Ковариация улавливает только линейную зависимость.

\prov $\mathrm{cov}(\xi,\xi^2) = -2.1\cdot10^{-4}$ по $2\cdot10^6$ значениям.

\zad{8} Для любого $a \in \R^m$ положим $\eta = a^{\top}(\xi-\mu)$:
\[
  a^{\top}\Sigma a
  = \sum_{i,j} a_i a_j \Exp\bigl((\xi_i-\mu_i)(\xi_j-\mu_j)\bigr)
  = \Exp\Bigl(\sum_i a_i(\xi_i-\mu_i)\Bigr)^{\!2} = \Exp\eta^2 \ge 0 .
\]
Симметричность очевидна из $\sigma_{ij} = \sigma_{ji}$. $\blacksquare$

Не положительно определена $\iff$ $\exists a \ne 0$: $\Exp\eta^2 = 0$
$\iff$ $\eta = 0$ п.\,н. $\iff$ $a^{\top}\xi = \mathrm{const}$ п.\,н., то есть
компоненты линейно зависимы и распределение сосредоточено на гиперплоскости.
Тогда $\det\Sigma = 0$, $\Sigma^{-1}$ не существует и плотность
\eqref{eq:mvn} не определена. То же условие делает вырожденной систему нормальных уравнений МНК.

\zad{9} $W_1,\dots,W_n$ -- полная группа попарно несовместных событий,
$\PP(W_i) > 0$, $\PP(X) > 0$. Дважды применяя определение условной вероятности
к $W_i \cap X$:
\[
  \PP(W_i \mid X)\PP(X) = \PP(W_i \cap X) = \PP(X \mid W_i)\PP(W_i)
  \Rightarrow
  \PP(W_i \mid X) = \frac{\PP(X \mid W_i)\PP(W_i)}{\PP(X)} .
\]
Так как $\{W_i\}$ -- разбиение, $X = \bigsqcup_i (X \cap W_i)$ и по аддитивности
\[
  \PP(X) = \sum_{i=1}^{n}\PP(X \mid W_i)\PP(W_i)
  \Rightarrow
  \sum_{i=1}^{n}\PP(W_i \mid X)
  = \frac{\sum_i \PP(X \mid W_i)\PP(W_i)}{\PP(X)} = 1 . \qquad\blacksquare
\]
Роль нормировки играет $\PP(X)$; при сравнении классов для фиксированного $x$
знаменатель одинаков, поэтому решающее правило строится по числителю.

\prov $\PP(W) = (0.2,\,0.5,\,0.3)$, $\PP(X \mid W) = (0.9,\,0.1,\,0.4)$,
$\PP(X) = 0.35$. По формуле $(0.5143,\,0.1429,\,0.3429)$, сумма $1$; прямое
моделирование $2\cdot10^6$ розыгрышей даёт $(0.5145,\,0.1426,\,0.3429)$,
макс. отклонение $2.8\cdot10^{-4}$.
