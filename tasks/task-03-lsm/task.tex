\subsection{Метод наименьших квадратов}

Значения $y_k$ измерены с ошибкой, зависимость ищется в виде $\est f(x, w)$ с
неизвестными параметрами $w$. Метод наименьших квадратов выбирает $w$, на
котором минимальна функция ошибки
\[
  E(w) = \frac12\sum_{k=1}^{N}\bigl(y_k - \est f(x_k, w)\bigr)^2 .
\]
В точке минимума все частные производные $\partial E/\partial w_i$ равны нулю.
В линейной регрессии $\est f = Ax + B$ и в полиномиальной $\est f = p_w(x)$
зависимость от параметров линейна, поэтому $E$ -- многочлен второй степени от
параметров, а условия $\partial E/\partial w_i = 0$ -- система линейных
уравнений. Это необходимое условие: любая точка минимума $E$ является решением
системы.

\subsection{Линейные системы}

\emph{Правило Крамера.} Квадратная система с определителем $\Delta \ne 0$ имеет
единственное решение $w_j = \Delta_j/\Delta$, где $\Delta_j$ -- определитель,
в котором $j$-й столбец заменён столбцом правых частей. Определитель отличен от
нуля тогда и только тогда, когда однородная система (все правые части нулевые)
имеет только нулевое решение. При $\Delta = 0$ система либо несовместна, либо
имеет бесконечно много решений: к любому её решению можно прибавить любое
решение однородной системы.

\emph{Теорема Фредгольма.} Пусть матрица системы $\sum_j a_{ij} w_j = b_i$
симметрична, $a_{ij} = a_{ji}$. Система совместна тогда и только тогда, когда
\[
  \sum_i b_i z_i = 0
  \quad\text{для каждого решения $z$ однородной системы}\quad
  \sum_j a_{ij} z_j = 0 .
\]
То есть правая часть должна быть ортогональна всем решениям однородной системы.
Для несимметричной матрицы условие то же, но однородная система берётся с
транспонированной матрицей.

\subsection{Корни многочлена}

Ненулевой многочлен степени не выше $M$ имеет не более $M$ различных корней.
Поэтому если многочлен степени не выше $M$ обращается в нуль в $M+1$ или более
различных точках, то все его коэффициенты равны нулю.

\section{Задания}

\zad{1}
\dano Линейная регрессия $\est f(x) = Ax + B$, функция ошибки
\[
  E(A,B) = \frac12\sum_{k=1}^{N}\bigl(y_k - Ax_k - B\bigr)^2 .
\]
Условия $\partial E/\partial A = 0$ и $\partial E/\partial B = 0$ дают систему
\begin{equation}\label{eq:lin}
  \begin{cases}
    \Bigl(\sum_k x_k^2\Bigr)A + \Bigl(\sum_k x_k\Bigr)B = \sum_k x_k y_k,\\[2mm]
    \Bigl(\sum_k x_k\Bigr)A + N B = \sum_k y_k .
  \end{cases}
  \tag{4}
\end{equation}

\treb Указать, когда разрешима система \eqref{eq:lin}, и объяснить, почему
решение в этом случае единственно. Выяснить, какой выборке соответствует
равенство нулю определителя системы.

\zachem Система \eqref{eq:lin} решается, когда прямую проводят по точкам
методом наименьших квадратов. Нужно знать, при каких выборках прямая
определяется однозначно.

\resh \emph{Определитель.}
\[
  \Delta = N\sum_k x_k^2 - \Bigl(\sum_k x_k\Bigr)^2
         = N\sum_k x_k^2 - N^2\bar x^2
         = N\sum_k (x_k - \bar x)^2 ,
\]
так как
$\sum_k (x_k - \bar x)^2 = \sum_k x_k^2 - 2\bar x\sum_k x_k + N\bar x^2
 = \sum_k x_k^2 - N\bar x^2$. Сумма квадратов равна нулю только когда все
слагаемые нулевые:
\[
  \Delta \ge 0, \qquad
  \Delta = 0 \iff x_1 = x_2 = \dots = x_N .
\]

\emph{Среди $x_k$ есть два различных, $\Delta > 0$.} По правилу Крамера система
\eqref{eq:lin} имеет единственное решение
\[
  A = \frac{N\sum_k x_k y_k - \sum_k x_k\sum_k y_k}{\Delta},
  \qquad
  B = \frac{\sum_k x_k^2\sum_k y_k - \sum_k x_k\sum_k x_k y_k}{\Delta} .
\]
Это решение -- единственная точка минимума $E$. Обозначим через
$d_k = y_k - Ax_k - B$ отклонения точек от найденной прямой, тогда уравнения
\eqref{eq:lin} записываются как
\[
  \sum_k d_k x_k = 0, \qquad \sum_k d_k = 0 .
\]
Для любого сдвига параметров $(a, b)$
\begin{align*}
  E(A + a, B + b)
  &= \frac12\sum_k \bigl(d_k - ax_k - b\bigr)^2 \\
  &= E(A, B) - a\sum_k d_k x_k - b\sum_k d_k + \frac12\sum_k (ax_k + b)^2 \\
  &= E(A, B) + \frac12\sum_k (ax_k + b)^2 .
\end{align*}
Значит $E(A + a, B + b) \ge E(A, B)$, и равенство только при $ax_k + b = 0$ для
всех $k$. Для двух различных $x_i \ne x_j$ вычитание этих равенств даёт
$a(x_i - x_j) = 0$, откуда $a = 0$, а затем $b = 0$.

\emph{Все $x_k$ равны, $\Delta = 0$.} Пусть $x_k = x_0$ для всех $k$. Тогда
$\sum_k x_k = Nx_0$, $\sum_k x_k^2 = Nx_0^2$, $\sum_k x_k y_k = Nx_0\bar y$, и
система \eqref{eq:lin} принимает вид
\[
  \begin{cases}
    Nx_0^2 A + Nx_0 B = Nx_0\bar y,\\
    Nx_0 A + NB = N\bar y .
  \end{cases}
\]
Первое уравнение -- это второе, умноженное на $x_0$, поэтому система
равносильна одному уравнению ${x_0A + B = \bar y}$. Его решений бесконечно
много: подходит любая прямая $y = Ax + B$, проходящая через точку
$(x_0, \bar y)$. Все они дают одно значение $E$, так как при $x_k = x_0$
функция $E$ зависит только от $x_0A + B$.

Такая выборка получается, когда все измерения проведены при одном значении $x$:
точки выборки лежат на одной вертикальной прямой $x = x_0$ (в частности, при
$N = 1$).

\emph{Ответ.} Система \eqref{eq:lin} разрешима при любой выборке. Решение
единственно, когда среди $x_k$ есть хотя бы два различных значения: тогда
$\Delta = N\sum_k (x_k - \bar x)^2 > 0$, а решение -- единственная точка
минимума $E$. Определитель равен нулю, когда все $x_k$ одинаковы, то есть точки
выборки лежат на одной вертикальной прямой; решений тогда бесконечно много.

\zad{2}
\dano Полиномиальная регрессия $\est f(x, w) = p_w(x) = \sum_{j=0}^{M} w_j x^j$,
функция ошибки
\[
  E(w) = \frac12\sum_{k=1}^{N}\bigl(y_k - p_w(x_k)\bigr)^2 .
\]

\treb Показать, что коэффициенты $w$, минимизирующие $E(w)$, являются
решениями системы
\[
  \sum_{j=0}^{M} a_{ij} w_j = b_i, \quad i = 0, \dots, M,
  \qquad
  a_{ij} = \sum_{k=1}^{N} x_k^{\,i+j},
  \quad
  b_i = \sum_{k=1}^{N} x_k^{\,i} y_k .
\]
Выяснить, всегда ли эта система разрешима.

\zachem Эту систему решает программа полиномиальной регрессии. Нужно знать,
есть ли у неё решение при любой выборке и когда оно единственно.

\resh \emph{Вывод системы.} В точке минимума $\partial E/\partial w_i = 0$,
$i = 0, \dots, M$. Производная $p_w(x_k)$ по $w_i$ равна $x_k^{\,i}$, множитель
$\frac12$ сокращается с двойкой:
\[
  \frac{\partial E}{\partial w_i}
  = -\sum_{k=1}^{N}\Bigl(y_k - \sum_{j=0}^{M} w_j x_k^{\,j}\Bigr)x_k^{\,i} = 0
  \iff
  \sum_{k=1}^{N}\sum_{j=0}^{M} x_k^{\,i+j} w_j = \sum_{k=1}^{N} x_k^{\,i} y_k .
\]
Меняем порядок суммирования в левой части:
\[
  \sum_{j=0}^{M}\Bigl(\sum_{k=1}^{N} x_k^{\,i+j}\Bigr) w_j
  = \sum_{k=1}^{N} x_k^{\,i} y_k ,
  \qquad\text{то есть}\qquad
  \sum_{j=0}^{M} a_{ij} w_j = b_i . \qquad\blacksquare
\]

\emph{Однородная система.} Разрешимость определяется решениями однородной
системы $\sum_j a_{ij} z_j = 0$. Её левая часть выражается через многочлен
$p_z$:
\[
  \sum_{j=0}^{M} a_{ij} z_j
  = \sum_{k=1}^{N} x_k^{\,i}\sum_{j=0}^{M} z_j x_k^{\,j}
  = \sum_{k=1}^{N} x_k^{\,i}\,p_z(x_k) .
\]
Если $p_z(x_k) = 0$ во всех узлах, то $z$ -- решение. Обратно, пусть $z$ --
решение. Умножим $i$-е уравнение на $z_i$ и сложим по $i$:
\[
  0 = \sum_{i=0}^{M} z_i\sum_{k=1}^{N} x_k^{\,i}\,p_z(x_k)
    = \sum_{k=1}^{N} p_z(x_k)\sum_{i=0}^{M} z_i x_k^{\,i}
    = \sum_{k=1}^{N} p_z(x_k)^2 ,
\]
поэтому $p_z(x_k) = 0$ для всех $k$. Итак, $z$ -- решение однородной системы
тогда и только тогда, когда многочлен $p_z$ обращается в нуль во всех узлах
$x_1, \dots, x_N$.

\emph{Когда решение единственно.} Пусть среди $x_1, \dots, x_N$ ровно $r$
различных значений $t_1, \dots, t_r$.

Если $r \ge M+1$, то многочлен $p_z$ степени не выше $M$ имеет $r \ge M+1$
корней, значит $z = 0$. Однородная система имеет только нулевое решение,
$\Delta \ne 0$, и по правилу Крамера решение системы существует и единственно.

Если $r \le M$, то многочлен $(x - t_1)\cdots(x - t_r)$ имеет степень
$r \le M$, не равен нулю и обращается в нуль во всех узлах. Его коэффициенты
дают ненулевое решение однородной системы, поэтому $\Delta = 0$.

\emph{Совместность при $\Delta = 0$.} Матрица симметрична, $a_{ij} = a_{ji}$,
и по теореме Фредгольма достаточно проверить, что правая часть ортогональна
решениям однородной системы. Для любого такого $z$
\[
  \sum_{i=0}^{M} b_i z_i
  = \sum_{k=1}^{N} y_k\sum_{i=0}^{M} z_i x_k^{\,i}
  = \sum_{k=1}^{N} y_k\,p_z(x_k) = 0 .
\]
Значит система совместна, и решений бесконечно много: к решению $w$ можно
прибавить любое решение $z$ однородной системы. Многочлены $p_w$ и
$p_{w+z} = p_w + p_z$ совпадают во всех узлах, поэтому все решения дают одно и
то же значение $E$.

\emph{Ответ.} Система разрешима при любой выборке, а её решение единственно
тогда и только тогда, когда среди $x_k$ есть $M+1$ различных значений или
больше (для этого нужно $N \ge M+1$). Иначе решений бесконечно много.

\emph{Замечание.} При $M = 1$, $w_0 = B$, $w_1 = A$ имеем $a_{00} = N$,
$a_{01} = a_{10} = \sum_k x_k$, $a_{11} = \sum_k x_k^2$, $b_0 = \sum_k y_k$,
$b_1 = \sum_k x_k y_k$, и система совпадает с \eqref{eq:lin}. Условие $r \ge 2$
при этом совпадает с условием из задания 1.
