# Нейронные сети и машинное обучение

Курс НГУ, магистратура. Учебное пособие: А. В. Пролубников, "Машинное обучение.
Нейронные сети", НГУ, 2025.

- `tasks/` - решения задач из пособия, LaTeX
- `labs/` - лабораторные работы, Jupyter
- `bachelor/` - код по курсу СМГМО, бакалавриат

Каждая задача и лабораторная лежит в своей ветке и попадает в `main` после сдачи.

## Установка

```
pip install -r requirements.txt
```

## Сборка PDF

```
cd tasks
make
```
